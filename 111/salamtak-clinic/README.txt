## طريقة التشغيل
1) افتح الملف index.html بمتصفحك مباشرة (نقر مزدوج) — لا حاجة لأي برنامج أو خادم.
2) أو استخدم ملحق "Live Server" في VS Code لتشغيل محلي مع إعادة تحميل تلقائية.

الصفحات (العربية):
- index.html    : الرئيسية
- services.html : الخدمات والتخصصات
- about.html    : من نحن
- contact.html  : التواصل + طلب موعد

الصفحات (الإنجليزية) في مجلد en/:
- en/index.html, en/services.html, en/about.html, en/contact.html

## تغيير اللغة
- زر "AR / EN" في رأس الموقع يبدّل بين العربية (RTL) والإنجليزية (LTR).
- التفضيل يُحفظ في المتصفح (localStorage) ويُطبّق على جميع الصفحات.

## الملفات
- css/style.css : كل التنسيقات (مشترك، RTL/LTR)
- js/script.js  : قائمة الجوال، معرض الصور، نموذج طلب الموعد
- images/       : الصور والشعار
- en/           : نسخة إنجليزية من الصفحات

## تعديل الصور
استبدل الملف بنفس الاسم في نفس المجلد:
- images/logo/logo.svg و favicon.svg : الشعار
- images/clinic/* : صور العيادة والمرافق
- images/doctors/* : صور الأطباء
- images/departments/* : صور التخصصات

## تعديل النصوص
عدّل النصوص مباشرة داخل ملفات HTML.
